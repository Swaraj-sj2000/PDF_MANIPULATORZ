# Logo Drop Zone

Drop the app logo here when ready.

Accepted source formats:

- `logo.svg`
- `logo.png`
- `logo.jpg`

Preferred:

```text
assets/logo_dropzone/logo.svg
```

Future packaging work should copy this into:

```text
native_app/resources/
packaging desktop icon assets
```

Do not commit large design exports. Keep only the final source logo and one small PNG preview if needed.
